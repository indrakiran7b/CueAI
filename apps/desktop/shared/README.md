# Desktop shared resources

Cross-platform desktop assets and build outputs used by both Windows and macOS Electron apps.

## Layout

| Path | Purpose |
|------|---------|
| `build-resources/web/` | Embedded Next.js standalone bundle (generated by `scripts/prepare-desktop-web.cjs`) |

## Shared code (future)

Several Electron modules are identical or nearly identical between `windows/` and `macos/` (store, protocol, shortcuts, updater, companion-store, ResizeHandles). Extract those into this folder when consolidating imports; do not duplicate full app trees per platform.
